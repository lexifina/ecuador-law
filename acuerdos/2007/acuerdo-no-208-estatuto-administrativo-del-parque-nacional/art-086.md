Art. 86.- El proceso de uso público administrará el Sistema de Manejo Turístico, el cual está integrado

por los siguientes sistemas:

Sistema de Control de la Operación Turística.

Sistema de Monitoreo Turístico.

Sistema de Ingreso de Visitantes.

Sistema de Guías Naturalistas.

Sistema para el Otorgamiento y Renovación de Patentes de Operación Turística.

Sistema de Manejo de Itinerarios.
