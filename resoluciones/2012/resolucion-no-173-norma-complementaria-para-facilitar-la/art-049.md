Artículo 49.- Para efectos de revaluación de registros de los productos se realizará un (1) ensayo de

eficacia; en caso de requerir otros usos se deberán ejecutar ensayos de eficacia adicionales para

ampliación de uso. Para productos con antecedentes de registro, con diez años o más de antigüedad, se

puede utilizar la modalidad de task force (esfuerzo compartido).
